lede: 每个 Transformer 层至少两次 norm：一行之内做两个归约（mean、var），再加一个仿射变换，全部融合在一个 kernel 里。

## 背景

LayerNorm（GPT-2、BERT）和 RMSNorm（LLaMA、Qwen、DeepSeek）在每一层出现两次。它们和 softmax 一样是 memory-bound 的逐行运算：一行一个 program，读一次、写一次。forward 还要把每行的 `mean` 和 `rstd`（1/σ）存下来，backward 要用。

- LayerNorm：`y = (x − μ) / sqrt(σ² + ε) · w + b`，σ² 是**有偏**方差（除以 N）。
- RMSNorm：`y = x / sqrt(mean(x²) + ε) · w`，不减均值、没有 bias，少一次归约。

## 要用到的知识

- 同一行内的**两次归约**：先求 μ，再求 `Σ(x − μ)²`。两遍法比 `E[x²] − E[x]²` 数值更稳定：后者在均值很大时会发生灾难性抵消。
- **mask 之后的值要再检查**：padding 处 load 的是 0，求和时没问题；但 `x − μ` 在 padding 处等于 −μ，不是 0，平方之前要用 `tl.where(mask, x − μ, 0)` 清零。
- 标量 store：`tl.store(mean_ptr + row, mean)`。
- `1.0 / tl.sqrt(v)` 或 `tl.rsqrt(v)`。

## 提示

::: hint 1 顺序
load x（fp32）→ `mean = sum(x) / N` → `xc = where(mask, x − mean, 0)` → `var = sum(xc²) / N` → `rstd` → load w、b → `y = xc · rstd · w + b` → 存 y、mean、rstd。
:::

::: hint 2 常见坑
- 平方前没清零 padding：N 不是 2 的幂时（7、333、1000），方差会偏大。
- 除以 `BLOCK_N` 而不是 `N`。
- 用了无偏方差（除以 N − 1）：`F.layer_norm` 用的是有偏的。
- mean / rstd 存成了 fp16：wrapper 分配的是 fp32 张量。
:::

::: hint 3 LayerNorm 主体
```python
x = tl.load(x_ptr + row * x_row_stride + cols, mask=mask, other=0.0).to(tl.float32)
mean = tl.sum(x, axis=0) / N
xc = tl.where(mask, x - mean, 0.0)
rstd = 1.0 / tl.sqrt(tl.sum(xc * xc, axis=0) / N + eps)
w = tl.load(w_ptr + cols, mask=mask, other=0.0).to(tl.float32)
b = tl.load(b_ptr + cols, mask=mask, other=0.0).to(tl.float32)
tl.store(y_ptr + row * y_row_stride + cols, (xc * rstd * w + b).to(y_ptr.dtype.element_ty), mask=mask)
tl.store(mean_ptr + row, mean)
tl.store(rstd_ptr + row, rstd)
```
:::

## 测完之后

- RTX 5090 实测（fp16，8192 行）：N = 8192 时 `F.layer_norm` 199 us，参考解 **176 us · 1524 GB/s**；N = 1024 / 4096 时快 5–8%。
- **RMSNorm 和 LayerNorm 一样快**（176 us 对 176 us）：两者读写的都是 M×N 的 x 和 y，多出的 bias 只有 N 个数，可以忽略；少的那次归约在寄存器里完成，也不花多少时间。memory-bound 的 kernel 里，只有减少**主要数据**的字节数才有用。
- **再融合一层**：vLLM 的 `fused_add_rms_norm` 把残差加也并进来：`x = x + residual; residual = x; y = rms_norm(x)`。改写你的 kernel 实现它，并算算省了多少字节。
- **N 更大怎么办**：官方 Triton LayerNorm tutorial 用 `for off in range(0, N, BLOCK_N)` 循环分段累加，再做第二遍归一化。
- backward：`dx` 需要 `mean`、`rstd` 以及两个行内归约（`Σ dy·w·x̂` 和 `Σ dy·w`）；`dw`、`db` 要跨行求和，需要第二阶段归约。这是很好的进阶练习。

::: answer 面试追问：为什么 LLM 普遍从 LayerNorm 换成了 RMSNorm？
RMSNorm 去掉了减均值和 bias，经验上对模型质量几乎没有影响，参数和计算更少、实现也更简单，更容易和残差加、量化等相邻操作融合。但单看 norm kernel 本身，它并不会明显更快：两者都是 memory-bound 的，时间由读 x、写 y 决定（本题实测两者耗时相同）。真正的收益来自融合：一个更简单的 norm 更容易和前后的操作合成一个 kernel，从而省掉整趟读写。
:::
